# Обзор

## Приложение для планирования встреч

Приложение для планирование встреч с клиентом. Например запись на услуги маникюра.

Бизнес устанавливает расписание, выкладывает свободные дни для записи. в одном дне может быть несколько окон для записи.

Клиент заходит и видит свободные окна, выбирает, записывается. Окно переходит в статус забронировано, но не подтверждено.

Бизнес обязан подтвердить запись. После подтверждения окно переходит в статус занято и отправляется уведомление тому кто забронировал окно о том, что его запись подтверждена.

За день и в день записи клиента уведомляет бот.
